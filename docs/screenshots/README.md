# Screenshots

These screenshots are captured at 1440x900 from a local Indago instance using
demo data. Display values that would identify a real target, lab instance,
provider endpoint, account or credential are replaced with generic values
(`shop.example.com`, `demo-app`, `demo-scan`, `api.example.com`) before capture.
No API keys, OAuth tokens, cookies, emails or customer data are included.

Files:

- `scan-overview.png` — a completed scan, its configuration and verdict counters
- `findings.png` — cross-project findings with confirmed and rejected verdicts
- `bounty.png` — YesWeHack program import surface, token field empty
- `settings.png` — collapsible Providers section with a masked key hint
