# Indago content-discovery wordlist: core paths (safe + standard levels).
#
# Provenance: hand-curated for this project from public, widely documented
# conventions (RFC 8615 well-known URIs, framework defaults such as Spring
# Boot Actuator, PHP/WordPress/phpMyAdmin layouts, common CI and deployment
# artefact names, and the paths security tooling has reported for years).
# No scraped list, no vendor corpus, nothing copied wholesale from a commercial
# wordlist. Every entry is a plain relative path, one per line; '#' starts a
# comment and blank lines are ignored.
#
# Selection rule: an entry earns its place only if finding it is actionable on
# a typical authorized engagement (an exposed admin surface, an API root,
# configuration/backup material, developer tooling, or a status/metrics
# endpoint). Entries are ordered roughly by expected value so the bounded
# per-scan budget spends its requests on the highest-signal paths first.
